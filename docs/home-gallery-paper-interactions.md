# Homepage gallery interaction architecture

This branch keeps CMS media configuration in `public_config_json` under `theme.galleries` and exposes the public gallery URLs through the existing section-media API. The river-start gallery and About flip gallery are capped at ten images.

The homepage uses native horizontal scrolling and CSS scroll snapping for the river-start gallery and Signature Experiences. The About image uses previous/next controls with a reduced-motion-aware calendar-style flip. The Why RI BUROM section uses an irregular clipped silhouette, layered parchment gradients, fibre/stain texture, and drop shadow to emulate torn aged paper without shipping a stock texture image.
